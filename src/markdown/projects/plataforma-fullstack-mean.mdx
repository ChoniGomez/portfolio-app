## Plataforma Web Fullstack MEAN

Solución web completa construida bajo el stack MEAN (MongoDB, Express, AngularJS, Node.js) para la gestión y administración de información.

### Características Principales
- SPA (Single Page Application) responsiva y reactiva estructurada modularmente en AngularJS.
- Backend en Node.js y Express para la gestión de endpoints y lógica empresarial distribuida.
- Base de datos NoSQL documental con MongoDB para modelos de datos ágiles y flexibles.

### Tecnologías Utilizadas
- **Frontend:** AngularJS
- **Backend:** Node.js, Express
- **Base de Datos:** MongoDB
