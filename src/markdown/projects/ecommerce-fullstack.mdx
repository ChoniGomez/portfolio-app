## E-commerce Full-Stack

Plataforma de comercio electrónico completa orientada a agilizar las ventas con integración automatizada de pedidos por WhatsApp.

### Características Principales
- Catálogo interactivo de productos con carrito de compras reactivo.
- Generación y envío automatizado de pedidos estructurados a través de WhatsApp.
- Base de datos relacional para gestión de stock, productos y órdenes.

### Tecnologías Utilizadas
- **Frontend:** React
- **Backend:** Node.js
- **Base de Datos:** PostgreSQL
- **ORM:** Prisma
