## GuaraSoft

Sistema de software empresarial enfocado en la gestión, control y trazabilidad del servicio de postventa en concesionarias y talleres automotrices.

### Características Principales
- Trazabilidad del ciclo completo de atención: recepción de vehículos, órdenes de trabajo, control mecánico y entrega final.
- Mapeo objeto-relacional y persistencia robusta utilizando Java Persistence API (JPA / Hibernate).
- Base de datos relacional PostgreSQL con alta integridad y consistencia transaccional.

### Tecnologías Utilizadas
- **Lenguaje & Backend:** Java
- **Capa de Persistencia:** JPA / Hibernate
- **Base de Datos:** PostgreSQL
