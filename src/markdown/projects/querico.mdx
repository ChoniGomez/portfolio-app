## QueRico!

Plataforma de e-commerce gastronómico diseñada para operaciones en tiempo real, gestión de inventario y pedidos comerciales directos.

### Características Principales
- Arquitectura Full-Stack completa con control dinámico de stock y promociones en tiempo real.
- Integración comercial automatizada con WhatsApp para agilizar el procesamiento y confirmación de pedidos.
- Base de datos relacional PostgreSQL con modelado para pedidos y catálogo gastronómico.
- Despliegue continuo en la nube utilizando Vercel (Frontend) y Render (Backend).

### Tecnologías Utilizadas
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express
- **Base de Datos:** PostgreSQL
- **Despliegue & Cloud:** Vercel, Render
