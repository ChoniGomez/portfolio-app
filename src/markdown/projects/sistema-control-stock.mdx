## Sistema Integral de Control de Stock

Aplicación web integral para el control de inventario, registro de entradas y salidas de mercadería, y generación de balances operativos.

### Características Principales
- Frontend interactivo y eficiente desarrollado en Vanilla JavaScript sin dependencias adicionales.
- Lógica de backend y procesamiento de transacciones implementados en PHP.
- Base de datos relacional MySQL para la administración estructurada de existencias y reportes.

### Tecnologías Utilizadas
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Backend:** PHP
- **Base de Datos:** MySQL
