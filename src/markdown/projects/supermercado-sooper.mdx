## Supermercado SOOPER

Plataforma corporativa de Punto de Venta (POS) y Backend para la administración comercial de cadenas de supermercados y venta minorista.

### Características Principales
- Arquitectura de microservicios y APIs RESTful construidas con Java y Spring Boot.
- Módulos de facturación electrónica, control de caja, gestión de depósitos y reposición de stock.
- Base de datos relacional MySQL con consultas optimizadas para alta concurrencia.

### Tecnologías Utilizadas
- **Backend:** Java, Spring Boot
- **Base de Datos:** MySQL
- **Arquitectura:** Servicios REST, Arquitectura en capas
