## CultiShop

Plataforma de comercio electrónico integral desarrollada con arquitectura escalable y tecnologías modernas para optimizar el rendimiento y la experiencia del usuario.

### Características Principales
- Arquitectura y despliegue (DevOps) en VPS DonWeb utilizando Nginx y contenedores Docker.
- Backend RESTful robusto y de alto rendimiento desarrollado con Node.js y Fastify.
- Modelado relacional avanzado con base de datos PostgreSQL.
- Integración fluida con interfaz de usuario en React.

### Tecnologías Utilizadas
- **Frontend:** React
- **Backend:** Node.js, Fastify
- **Base de Datos:** PostgreSQL
- **DevOps e Infraestructura:** Docker, Nginx, VPS DonWeb
