## Smart Lock con Reconocimiento Facial

Sistema de seguridad inteligente para autenticación biométrica y desbloqueo de cerraduras electrónicas.

### Características Principales
- Detección y reconocimiento facial de usuarios registrados mediante Python.
- Protocolo inalámbrico de comunicación Bluetooth entre el servidor de visión y el módulo actuador.
- Control del mecanismo de la cerradura electromecánica con Arduino programado en C++.

### Tecnologías Utilizadas
- **Visión y Lógica:** Python
- **Firmware y Microcontroladores:** Arduino, C++
- **Conectividad:** Bluetooth (módulos serie HC-05/HC-06 o ESP32)
